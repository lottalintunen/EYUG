# EYUG
Timing and stratification in university attainment over the life course
Juho Härkönen & Lotta Lintunen
This repository consists of the code that identifies the procedures followed to produce the dataset analyzed and to replicate the analysis in the article.
The authors cannot share the data underlying this article publicly due to ethical and privacy requirements of the data provider, Statistics Finland. 
Most of the raw data used is updated continuously.
Data version used for analysis: 09/04/2026
Programme used for the analysis: Stata 18 
1. data EYUG.do file consists of the code and comments for constructing the datasets used in the manuscript.
2. analysis EYUG.do file consists of the code and comments to replicate the analysis in the manuscript.
